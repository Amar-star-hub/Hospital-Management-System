# Bill Management System

A simple and efficient web application for managing hospital bills, appointments, and patient records.

## Features

- User authentication
- Patient registration and management
- Appointment scheduling
- Billing management
- Dashboard for quick insights

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the backend directory:
   ```
   cd bill/backend
   ```
3. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
4. Run the application:
   ```
   python app.py
   ```

## Usage

- Access the application at `http://localhost:5000`
- Use the login page to authenticate as an admin.
- Manage patients, appointments, and bills through the dashboard.
